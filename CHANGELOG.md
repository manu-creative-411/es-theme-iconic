# Unreleased


* Thanks to [Manu](https://github.com/manutortosa-collab)'s tremendous work, the theme now supports 93 new systems, including plenty of new collections with high-quality fanarts.
* Add translations of all the UI and the systems metadata in 18 languages (spanish translation by [Manu](https://github.com/manutortosa-collab)).
* Add video previews to the game details page (when available).
* Add option to enable loading logos from SVG files for sharper and scalable graphics (thanks [Manu](https://github.com/manutortosa-collab)).
* Grid view: 2:3 tiles (SteamGridDB 600x900 boxart), the selected tile is no longer clipped, and a sliver of the previous/next row is shown at the top and bottom as a hint that there are more games (the grid extends down to 0.965, with a fade at the bottom).
* Add the "Full Grid" view: full-screen grid with the system logo at the top center and the background fading into the color scheme at the top and bottom. Select it from the gamelist options.
* Default transition between the system view and the game lists is now `fade` instead of `instant`.
* Add the `Logo Region` option (Europe, USA, Japan) to load regional SVG logos (`<system>/<region>.svg`, `<system>/<scheme>-<region>.svg` or `<system>-<region>.svg`), with a fallback to other regions and to generic logos.
* SVG logos can now have separate versions for each color scheme: when enabled, `_inc/logos-svg/<system>/light.svg` or `dark.svg` take precedence over `_inc/logos-svg/<system>.svg`, which in turn takes precedence over the bitmap logo.
* Add the `Game List Position` option (`Right` by default, or `Left`) to swap the game list/grid with the info area (system logo or game details) in the `basic`, `detailed` and `grid` views, like the original ES-DE theme. The swapped panel images (`*-left.png`, `*-right.png`) are generated by `_tools/make_swapped_panels.py`.
* Add the Retrobox distribution option to the theme settings.
* Add the Knulli, Recalbox, RetroPie and EmuELEC distribution options. Selecting a distribution loads its splash screen background from `_inc/splash/<distribution>.svg` or `.png` (1080p minimum recommended), falling back to the default background if absent.
* Splash progress bar now fills from left to right instead of from the center.
* Add controllers status icons in carrousel (thanks [Manu](https://github.com/manutortosa-collab)).
* Simplfy the customization of theme backgrounds (thanks [Manu](https://github.com/manutortosa-collab)).
* Fix automatic collections not dynamically populating the games list (thanks [Manu](https://github.com/manutortosa-collab)).
* The theme options are now translated into Basque, Galician, Czech, Slovak, Hungarian, Greek, Finnish, Norwegian and Ukrainian, in addition to the existing languages. The options added later (`Game List Position`, buttons style) were missing in every language except Spanish: they are now translated everywhere, and the `Standard` button style label, which had no text at all, has been added.
* The dark color scheme and the vector (SVG) logos are now the defaults.
* Fix the splash screen showing the EmuELEC artwork (and the light color scheme) while the `Distribution` and `Color Scheme` options had never been changed: `splash.xml` did not declare the default value of those options, so every `ifSubset` was true and the last one won. With `None`, the default splash artwork is now used.
* Bitmap logos now follow the same organization as the vector ones: `_inc/logos/<system>/<scheme>[-<region>].webp`, `<region>.webp` and `<system>-<region>.webp` are supported, with the same precedence rules. The variants of every system that already had them in `_inc/logos-svg/` have been generated with the new `_tools/make_bitmap_logos.py`.

* Adapt the theme to the `Theme Font Scale` setting of EmulationStation: the game list shows fewer rows as the font grows instead of crowding them, the texts laid out in a fixed space stop growing beyond `133%` to avoid overlapping, and the bottom bar stays centered. Add the `Game List Rows` option to force a fixed number of rows (odd numbers from 7 to 21). The game list panels, which have the row separators baked in, are generated for each number of rows by `_tools/make_gamelist_panels.py`.
* Game list: long titles are now shortened with an ellipsis instead of being cut at the edge of the list, and the selected one scrolls horizontally within the same margins (each row is drawn by an item template).

# 1.0.0 (2025-02-06)
